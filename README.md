## HOW TO SETUP
Run the following in order of appearance
```bash
# Create virtual environment
python -m venv .venv

# Activate it
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

Then to run the UI
```bash
streamlit run app.py
```
